# geswat-site

Static geswat website in Turkish, English and Spanish.

Build: `python3 scripts/build-site.py`

Preview: `python3 -m http.server 4173 --bind 127.0.0.1`

GitHub Pages: `main` → `/ (root)`. Only website sources and assets belong in this repository.

Legal copy lives in `data/legal.json`; keep it consistent with the app when policies change.
